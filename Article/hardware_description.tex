\section{Hardware description}
he hardware described here is a signal interposer intended for use with the Tiny Tapeout Application.
With appropriate software it can be made to help with various silicon validation tasks.
\begin{itemize}
    \item The Everything PMOD can be programmed to pass through signals. 
    This means that it can also rearrange signals to correct for any potential pinout errors in the original design compared to a desired PMOD.
    \item The PMOD can be programmed to read various digital signals from its inputs and report the values back to the computer. 
    Combined with passing through the signal this can make it much simpler to capture project waveforms.
    \item The PMOD can be programmed to emulate various different pieces of external hardware to help simplify project validation.
\end{itemize}
