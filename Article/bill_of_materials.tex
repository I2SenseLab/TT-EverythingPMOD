All components in the bill of materials were selected from parts available 
through the JLCPCB assembly service. This was done to simplify reproduction 
of the hardware, since the same fabrication order can include PCB 
manufacturing, component sourcing, and automated assembly. 
Passive components such as resistors and capacitors use standard 
0402 and 0805 footprints where possible, allowing substitution with 
equivalent values from other suppliers if required. 
The designators in the bill of materials match the schematic and 
layout files directly, so each entry can be traced back to the 
corresponding component in the design files.
